\# PRAHARI



AI-powered multimodal threat detection and surveillance system.



\## Current Focus



Lightweight YOLO-based visual threat detection with explainable AI and automated voice alerts.



\## Target Threat Classes



\- Person

\- Handgun

\- Rifle

\- Knife

\- Grenade



\## Project Pipeline



Dataset → YOLO Detection → Threat Assessment → Explainability → Voice Alert



\## Future Extensions



\- Thermal imagery

\- LiDAR

\- Radar/RF sensing

\- Acoustic sensing

\- Multimodal sensor fusion
